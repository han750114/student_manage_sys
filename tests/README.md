# 自動化測試計畫

目前只建立測試目錄，尚無功能測試。執行結果為 0 個測試時，不代表功能通過。

使用 Python 標準函式庫 unittest：

```powershell
python -m unittest discover -s tests -v
```

新增檔案以 test_ 開頭，例如 test_management.py。測試直接呼叫核心函式，不依賴 input()。
存取測試使用 tempfile.TemporaryDirectory，不覆寫 data/ 內的專案資料。

## F1～F6 驗收目標

至少 30 個案例：正常、邊界、錯誤及衝突各至少 10 個。

| 類型 | 優先案例 |
|---|---|
| 正常 | 新增學生與課程、查詢、存檔後讀回、產生課表 |
| 邊界 | 學分剛好達上限、最後一個名額、星期 7、節次 c、相鄰時間區間 |
| 錯誤及衝突 | 重複代號、無效學分、非法節次、課程額滿、多個衝突同時存在、損壞資料 |

至少準備 20 門課程、15 名學生、5 間教室；F4 至少 10 項活動。
