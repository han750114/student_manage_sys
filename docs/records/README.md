# 開發紀錄

複製下列模板另存新檔，不覆寫過去的紀錄。
建議檔名：YYYY-MM-DD-紀錄類型-成員或功能.md。
紀錄必須反映實際工作；空模板不代表完成繳交。

## 每週會議與 Iteration Review

- 日期、出席成員、討論照片位置：
- 本週完成／未完成：
- 討論事項與決議：
- 分工、主要負責者、協作者、下週目標：
- 需求或介面修改及原因：
- Commit／Merge、測試結果、未解決缺陷：

## 個人工作與 Code Review

- 成員、日期、負責功能、完成內容：
- Git 提交：
- 函式 Input／Process／Output／Boundary 或 Error Case：
- 問題與解決方式：
- Reviewer、檢視版本、意見、修改及驗證：

## AI 協作

- 日期、功能、原始程式版本：
- 問題與詢問前的想法：
- 第一輪 Prompt、AI 建議摘要：
- 第二輪 Prompt、修改提問的原因、AI 建議摘要：
- 採納或拒絕、理由：
- 驗證方法、測試案例、實際結果、修改後版本：
- 有效與錯誤建議、個人反思：

## TDD（第 10 週起）

- Requirement：
- Test：
- Red：執行指令、實際失敗輸出與版本：
- Green：最低限度實作、通過輸出與版本：
- Refactor：修改理由：
- Regression Test：執行指令與實際結果：

必須於開發過程中保留紀錄，不得完成實作後才補寫成 TDD。
